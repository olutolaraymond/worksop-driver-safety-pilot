# Worksop Driver Safety Pilot

GitHub Pages deployment for the Phase 1 pilot.

## Publish
1. Create a public GitHub repository named `worksop-driver-safety-pilot`.
2. Upload all files from this package to the repository root.
3. In **Settings > Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Copy the exact GitHub Pages address and test it on a phone before creating the QR code.

## Controls
- Do not upload the source PDFs.
- Do not add personal data, credentials, analytics, internal links, or employee contact details.
- Enable a language only after independent safety-translation review.
- Keep a downloaded backup of each release.


## Version 1.3 team translation review

All listed European language buttons are enabled. English remains the controlled master. Non-English options open machine-translated draft copies when the site is hosted, and are labelled for fluent-speaker review. Do not use non-English drafts for live safety communication until they are independently checked and approved.

## Voice and language
All listed language buttons are active for hosted machine-translation review. Selecting a language stops current audio and sets the matching voice code. The device must have a suitable voice installed.
